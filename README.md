# PTA適正化推進委員会 公開サイト

このリポジトリは、PTA適正化推進委員会の GitHub Pages 公開サイトです。

公開URL:

- https://ptaorg.github.io/pta/

## 基本方針

このサイトは、PTAに関する教育委員会回答、公文書開示資料、実物PTA資料、制度分析を整理する研究・資料公開サイトです。

Google Drive は原本PDF等の保管庫として使います。ただし、読者の閲覧・検索・解説・資料確認は、原則として GitHub Pages 上のサイト内で完結させます。

Googleサイトへの誘導、Googleサイトへの移管導線、Googleサイトを主表示先にする構成は採用しません。

## 今後の重点

1. 各地から取り寄せた実際のPTA資料群を、自治体別・学校別・論点別に整理した資料庫を作る。
2. 資料はPDFリンクだけで終わらせず、可能な範囲で画像化し、サイト内に画像と解説を表示する。
3. 保護者、PTA役員、学校管理職、教育委員会、研究者・記者向けの立場別ページを充実させる。
4. 教育委員会向けには、PTAを直接統制するのではなく、学校側関与を所掌範囲として点検し、学校宛通知・事務連絡・ガイドライン整備へ進む構成にする。

## 資料庫の設計

資料ページでは、可能な限り次の情報を整理します。

- 資料名
- 自治体名
- 学校名
- 年度
- 取得方法
- 資料種別
- 論点タグ
- 検証状態ラベル
- この資料で見るべき点
- 資料画像
- ページごとの解説
- 制度上の問題点
- 教育委員会が確認すべき事項
- 学校に求める是正事項
- 原本PDFリンク
- 関連ページ

## 禁止事項

- 法的主張、教育委員会回答本文、公文書本文、資料本文、引用文を勝手に書き換えない。
- 存在しない法令、判例、行政見解、統計、URLを追加しない。
- 未確認資料を確認済みとして扱わない。
- Googleサイトへのリンク・誘導・移管導線を追加しない。
- Driveフォルダだけを貼って終わる資料ページを作らない。
- 既存ページを大量削除しない。
- デザインを全面刷新しない。
- カード型ハブだけを増やし、本文のないサイトにしない。

## 更新時の確認

公開前またはコミット前に、最低限次を確認します。

1. `sitemap.xml` に `https://ptaorg.github.io/pta/...//` 形式のURLが残っていないこと。
2. Googleサイトへのリンクが追加されていないこと。
3. `index.html`、`materials-catalog.html`、`responses.html`、`edu.html`、`guide-board.html` の主要導線が破綻していないこと。
4. 教育委員会回答本文・資料本文・引用文が意図せず変更されていないこと。
5. Google Driveリンクは原本確認用・補助リンクとして扱われていること。

## 主要ファイル

- `index.html`：トップページ
- `materials-catalog.html`：実物資料カタログ・資料庫入口
- `responses.html`：全国教育委員会回答DB
- `edu.html`：教育委員会向け指針
- `guide-parent.html`：保護者向けページ
- `guide-pta.html`：PTA役員向けページ
- `guide-board.html`：学校・教育委員会向けページ
- `data/materials-manifest.json`：公開用資料登録ファイル
- `sitemap.xml`：検索エンジン向けサイトマップ
- `AGENTS.md`：AI・作業者向け運用ルール

## 注意

このサイトの資料・解説を引用、提出、照会に使う場合は、資料本文、作成主体、年度、取得方法、開示決定文書、個人情報処理の有無を必ず確認してください。
