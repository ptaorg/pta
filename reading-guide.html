読み方ガイド

自分の立場と目的に合わせて、読む順番を選ぶためのページです。

結論：このサイトは、立場別・論点別・根拠別に読めます。最初から全ページを読む必要はありません。

自分が「何を確認したいのか」によって、読む順番を変えてください。ただし、各主要ページは単独で読めるように作っています。表のリンクは必須の移動先ではなく、必要になった時の深掘り先です。

立場別目的別資料別最短ルート深掘り

立場別に読む

読者この順番で読む読んだ後にできること
保護者保護者向けガイド → 入会 → 会費徴収 → 個人情報 → 照会文例学校・PTAに、記録と根拠を確認できる。
PTA役員PTA役員向けガイド → 会員管理 → 会計・監査 → 個人情報 → 学校との分離PTAを任意団体として運営するための見直し項目を整理できる。
学校管理職学校・教育委員会向けガイド → 指針 → チェックリスト → 学校向け診断学校側が止めるべき関与と、許容される連絡調整を分けられる。
教育委員会教育委員会向け導線 → 指針 → 回答DB → チェックリスト → 診断PTA内部統制ではなく、学校側関与の是正として通知を組み立てられる。

目的別に読む

  1. 全体像だけ知りたい：3分で読む と 1ページ要約 で、5大論点と学校・PTAの分離を確認します。
  2. 自校の状態を点検したい：監査アプリ と チェックリスト を使い、入会・会費・個人情報・教職員関与を確認します。
  3. 行政に説明したい：教育委員会向け指針、回答DB、主張根拠対応表 を使い、主張と資料を対応させます。
  4. 文書を出したい：提出キット、情報公開請求キット、聞き取り記録テンプレート を使います。

手元の資料から読む

すでに学校配布文書やPTA資料がある場合は、文書の種類から入ると早いです。ひとつの文書に複数の論点が混ざっている場合は、文書全体で判断せず、加入、会費、個人情報、学校関与に分けて読みます。

手元の資料先に読むページ確認する点

口座振替・徴収明細会費徴収・学校徴収金との混在請求主体、口座、返金、未納対応、学校徴収金との関係
個人情報同意書・名簿個人情報・第三者提供同意提供先、利用目的、同意対象、拒否方法、取得元
役員選出・当番表役員選出・非会員情報対象者、名簿の取得元、未加入者・非会員の扱い
学校配信・施設利用学校施設・媒体利用・学校業務とPTA事務学校名義、回収主体、職員関与、施設・備品の利用手続

初見の人に渡す最短ルート

まずはこの3ページ

3分で読む、PTA問題一枚要約、立場別ガイドで十分です。そこから必要に応じて、教育委員会向け指針や回答DBに進みます。

深掘りする場合

  • 制度を確認する：法制度マップ、教育委員会向け指針、論考・研究を読む。
  • 実態を確認する：全国教育委員会回答DB、地図、資料館、実物文書を読む。
  • 提出用に整える：根拠台帳、主張根拠対応表、引用ガイド、提出キットを使う。
