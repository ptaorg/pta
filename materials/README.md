# materials フォルダの使い方

このフォルダは、あとから実物文書PNG、動画、文字起こしを入れるための受け皿です。

## 推奨構成

- documents/ : 実物文書PNG・PDF
- interviews/ : インタビューMP4
- thumbnails/ : 動画サムネイル
- captions/ : 動画文字起こし・要約

## 公開前チェック

1. 児童名・保護者名・住所・電話番号・学校名などの個人情報をマスキングする。
2. 資料ID、資料名、作成主体、年度、取得経路、確認状態を記録する。
3. 新聞記事画像など、転載許諾が必要になり得るものは本文要約にとどめる。
4. 資料から直接いえる事実と、委員会の分析コメントを分ける。
