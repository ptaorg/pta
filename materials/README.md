# materials フォルダの使い方

このフォルダは、実物文書PNG、PDF、インタビュー動画、文字起こしを後から差し込むための受け皿です。
GitHub Pages にそのまま載せる前提で、ファイル名・資料ID・公開可否をそろえて管理します。

## 推奨構成

```text
materials/
├ documents/      実物文書PNG・PDF
├ interviews/     インタビューMP4
├ thumbnails/     動画サムネイル
└ captions/       動画文字起こし・要約
```

## ファイル名ルール案

```text
DOC-JOIN-001.png       入会案内・申込書
DOC-FEE-001.png        会費徴収・学校徴収金関連
DOC-INFO-001.png       個人情報同意・名簿関連
DOC-ROLE-001.png       役員選出・当番表関連
DOC-BOARD-001.pdf      教育委員会回答・開示資料
MOV-INT-001.mp4        インタビュー動画
CAP-INT-001.txt        動画文字起こし
```

## 差し込み時の記録項目

`data/materials-manifest.template.json` をコピーして、資料ごとに次を記録します。

- 資料ID
- 資料名
- 種別
- 作成主体
- 配布主体
- 回収主体
- 年度・日付
- 取得経路
- 公開状態
- マスキング状態
- 関係する論点
- 資料から直接確認できる事実
- 委員会側の分析コメント

## 公開前チェック

1. 児童名・保護者名・住所・電話番号・学校名・QRコード・管理番号を確認する。
2. 学校名を出すか、自治体名だけにするかを資料ごとに判断する。
3. 新聞記事画像など転載許諾が必要になり得るものは、画像転載ではなく要旨説明にとどめる。
4. 資料から直接いえる事実と、委員会の分析コメントを分ける。
5. 提出資料・公文書・学校配布文書・個人提供資料を混同しない。
6. 動画は、顔・音声・学校名・家庭事情が含まれる場合、公開範囲と同意を確認する。

## HTMLへの掲載方針

- まず `actual-pta-documents.html` に資料の読み方を載せる。
- 次に `archive.html` の該当論点へ誘導する。
- 個別資料は、資料ID・資料名・作成主体・年度・公開状態を必ず併記する。
- 画像だけを貼らず、本文で「何が確認できる資料なのか」を説明する。
