教育委員会向け
最初に読む5ページ

PTA運営を「学校の善意」ではなく、公私分離・個人情報・会費徴収・教職員関与・根拠資料の順に確認するための導線です。

5ページ順に読む回答DBを見る教育委員会向け診断
根拠レベル

この導線は、サイト内ページの読む順番を示すものです。提出・引用に使う場合は、各ページの原資料・回答本文・開示資料を再確認してください。

教育委員会回答あり資料導線監査ツール原資料確認推奨
表示の意味

使い方

教育委員会・学校管理職が短時間で全体像を把握するため、読む順番を固定しています。ここでは新しい法的断定を追加せず、既存ページ・回答DB・監査ページへの導線を整理しています。

注意：このページ自体はナビゲーションです。個別の法的判断・行政判断には、各ページで示される原資料、教育委員会回答、開示資料、関係法令の確認が必要です。

Reading Path

最初に読む5ページ

教育委員会側で確認すべき順番に並べています。

全体像3分で読む 5大論点論点整理 学校・教委向け公私分離 回答DB全国回答 診断確認項目

全体像：PTA問題を学校問題としてではなく、公私分離問題として読む

まず、PTAを学校組織と同一視せず、任意団体・学校・教育委員会の境界を整理します。

  • 読むページ：3分で読む
  • 確認する点：入会意思、会費、個人情報、教職員関与、学校媒体利用

5大論点：問題を個別苦情ではなく、確認項目に分解する

教育委員会が対応する場合、論点を分けないと、任意団体論だけで処理されやすくなります。

  • 読むページ：PTA問題の5大論点
  • 確認する点：加入、個人情報、徴収、職務、施設・媒体

学校・教育委員会向け：学校側の関与範囲を確認する

PTA自体は任意団体であっても、学校が徴収・配布・名簿提供・事務従事に関与する部分は別に点検が必要です。

  • 読むページ：教育委員会・学校へ
  • 確認する点：校務分掌、事務分掌、職務専念義務、学校徴収金、個人情報提供

全国回答DB：他自治体の回答傾向と照会項目を確認する

同梱DBでは、自治体別・質問類型別に教育委員会回答を確認できます。短文・日付未確認などはフラグで区別しています。

  • 読むページ：教育委員会回答DB
  • 補助ページ：全国マップ
  • 注意：自動フラグは断定ではなく、原資料確認を促す表示です。

監査・点検：自自治体の運用を確認項目に落とす

最後に、学校管理職・教育委員会の立場で、現在の運用がどこに該当するかを点検します。

  • 読むページ：教育委員会向け診断
  • 関連ページ：学校管理職向け診断
  • 次の作業：必要に応じて 提出キット や 情報公開・監査 に進む

教育委員会側で最初に確認する資料

  • 学校徴収金・PTA会費・教材費等の徴収方法が分かる文書
  • PTA入会申込書、同意書、退会届、非会員対応の文書
  • 学校が保有する児童・保護者情報をPTAに渡す根拠資料
  • 校務分掌、事務分掌、職務専念義務免除、兼職兼業等に関する運用文書
  • 学校施設・学校配布物・学校メール・学校HPをPTAが使う場合の根拠文書
確認上の注意：この一覧は実務上の確認項目であり、個別自治体にこれらの文書が必ず存在することを断定するものではありません。存在しない場合は「不存在」や「作成していない」という回答自体が、運用実態を確認する材料になります。
